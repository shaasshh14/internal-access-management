# Internal Access Management (IAM)

An enterprise-grade Internal Access Management (IAM) platform built using modern software engineering practices.

The system streamlines the lifecycle of user access requests, approvals, role management, auditing, and reporting within an organization while following scalable enterprise architecture.

---

## Project Overview

This project is divided into multiple modules following a feature-first architecture.

```
Internal_Access_Management/
│
├── iamfrontend/          # React + TypeScript Frontend
├── iambackend/           # Spring Boot Backend
├── docs/                 # Architecture & Documentation
├── infrastructure/       # Docker, Nginx, Deployment
├── scripts/              # Automation Scripts
└── README.md
```
